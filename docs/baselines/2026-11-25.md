# Baseline — 2026-11-25 (git tag `baseline-2026-11-25`)

A fixed point to measure the next phase against. Core development pauses here. The next phase, an audit
and consolidation by a senior architect session, starts from this tag ([handoff brief](../handoff/senior-architect-brief.md)).
Every number below was measured on this commit (Apple M5 Pro, arm64, macOS) unless it says otherwise.
